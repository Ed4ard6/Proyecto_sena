# Proyecto SENA – Lavandería Megarápido (versión desplegada)

Versión del sistema de información para lavandería preparada para el servidor de presentación del proyecto final del **Técnico en Programación de Software del SENA (2022)**. Incluye los recursos multimedia (imágenes y videos) del sitio.

El desarrollo completo, con el historial de cambios, la documentación y el script de la base de datos, está en el repositorio principal:

👉 **[lavanderia_megarapido](https://github.com/Ed4ard6/lavanderia_megarapido)**

**Stack:** PHP, MySQL, HTML, CSS / SCSS y JavaScript.
